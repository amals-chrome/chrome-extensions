RunJS

把 CSS 与 JavaScript 绑定到任意网址。从弹窗或 Dashboard 打开，页面到达后再注入。代码留空则只打开网址 — 无需站点访问权限。

Chrome 网上应用店 隐私政策 全部扩展

为什么选 RunJS

为你天天用的网站准备一键工作流

在 Dashboard 保存名称、目标网址与可选的 CSS/JS。全部留在本机 — 没有云端脚本库，没有广告，没有追踪。

打开并注入

点击已保存条目即可打开网址并在加载后注入。CSS/JS 为空则仅打开。

本地脚本库

脚本、偏好与草稿保存在本机 Chrome 存储中。

适配真实页面

跟随跳转，支持 SPA 与 iframe，注入时机可配置。

功能

你能做什么

  • Dashboard — 脚本库含常规 / CSS / JS / 设置，CodeMirror 编辑器、格式化、网址测试与草稿恢复。
  • 弹窗 — 搜索与筛选；点击打开并注入，或在代码为空时仅打开。
  • 注入 — 主机 + 路径前缀匹配；隔离环境或页面主环境；开始 / DOM 就绪 / 加载完成 / 空闲 / 延迟；刷新后可保持。
  • 脚本库工具 — 导入/导出 JSON、批量删除、拖拽排序、导入冲突处理。

运行要求

Chrome 135+

在 Chrome 138+ 上注入已保存脚本时，请打开 chrome://extensions → RunJS 详情 → 开启「允许运行用户脚本」。仅在你保存了注入代码的来源站点上才会申请站点访问权限。

开始使用

从 Chrome 网上应用店安装 RunJS，或先阅读隐私政策。
