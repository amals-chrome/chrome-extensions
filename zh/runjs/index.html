两种用法

一点打开并注入，或只当网址快捷方式

在 Dashboard 保存名称、目标网址与可选的 CSS/JS。默认本地优先；需要时再开 Google Drive 同步。

核心亮点

适配真实页面

跟随跳转，支持 SPA 与 iframe，注入时机可配置。

注入范围可控

指定网址或所有站点；匹配模式、自动注入，以及按脚本启用/禁用。

Monaco 编辑器

Dashboard 内补全、悬停与 Less/Sass；主题与字体跟扩展设置同步。

权限克制

有注入代码才申请站点访问；拒绝仍可本地保存。Chrome 138+ 还需开启「允许运行用户脚本」。

运行要求

Chrome 135+

最低要求 Chrome 135+。在 Chrome 138+ 上注入已保存脚本时，请打开 chrome://extensions → RunJS 详情 → 开启「允许运行用户脚本」。仅在你保存了注入代码的来源站点上才会申请站点访问权限。
