3. 服务内容

RunJS 允许你绑定名称、目标网址与可选的、由你编写的 CSS/JavaScript；一次操作可打开该网址，并在保存了代码时于匹配站点加载后注入。若 CSS 与 JS 均为空，则可能仅打开网址，注入无需站点访问权限。

常见本地功能包括 Dashboard 脚本库、弹窗启动器、匹配模式、注入时机与执行环境、JSON 备份导入导出，以及界面偏好（语言、主题、字体、布局）。功能可能随 Chrome API 与产品迭代变化。

  • 服务以本地优先：除非你主动开启并授权云端选项，脚本库与偏好保存在本机 Chrome 存储中。
  • 运营者默认不运营用于托管你脚本库的自有后端。
  • 扩展内不含广告，也不含用于追踪你浏览行为的第三方分析 SDK。
  • Chrome 版本要求（当前为 Chrome 135+；Chrome 138+ 需开启「允许运行用户脚本」）见商品页与应用内说明。注入功能须满足这些要求。
