RunJS

隐私政策

更新日期：2026-10-16

RunJS 以本地优先：默认将脚本与偏好保存在本机 Chrome 存储中。我们不运营脚本库后端，不会把脚本正文或页面内容上传到我们的服务器，也不含分析或广告追踪。可选的 Google Drive 同步（需你主动开启）会把脚本库副本存入你 Google 账号下的 Drive 应用数据区，而非 RunJS 服务器。

我们存储的数据

以下内容保存在本机 Chrome 存储中（可选 Drive 脚本库副本见下方条目与「网络使用」）：

  • 脚本库条目（名称、网址或所有站点范围、CSS/JS、含自动注入/启用等运行设置、可选缓存图标）
  • 语言、主题、字体，以及可选功能偏好（网站图标嗅探、网页右键菜单）
  • Dashboard 编辑中的未保存草稿（session 存储；浏览器会话结束后清除）
  • 打开标签页过程中的短期注入任务（session 存储）
  • 弹窗角标用的短期注入结果（local 存储）
  • 是否已关闭工具栏固定提示（local 存储）
  • 可选 Drive 同步在本机的状态（是否开启、关联的 Google 邮箱、上次同步时间 / 错误）— 开启同步后，脚本库副本保存在你的 Drive 应用数据区

我们不收集的数据

  • 不上传你的脚本、网址或页面内容到 RunJS 服务器（可选 Drive 同步仅走 Google API 与你的 Google 账号）
  • 不含分析 SDK、广告追踪，不出售或分享个人数据
  • 不通读浏览历史 — 仅在判断何时注入时检查标签页 URL：与 RunJS 发起运行相关的标签（含复用已打开且匹配的标签），以及开启了「自动注入」且匹配的页面导航。不会上传或把 URL 存成浏览历史
  • 不下载远程脚本 — 只注入你本地保存的代码

网络使用

  • 打开或测试目标网址时，由浏览器正常访问该站点（不经过我们代理）
  • 列表图标优先使用 Chrome 本地图标缓存（`favicon` 权限）。已授权站点访问且开启网站图标嗅探（设置 → 功能，默认开）时，也可能从目标站获取：读取页面 HTML 查找 `rel=icon`，再尝试常见根路径 favicon；响应会校验为图片。无可用缓存、未授权或关闭嗅探时使用内置默认图标（不向第三方图标服务请求）
  • 可选 Google Drive 同步：通过 Google OAuth 与 Drive API，在你的 Drive 应用数据区读写脚本库文件（按脚本分文件 + 索引）。流量发往 Google，而非 RunJS。可随时断开或改回仅本机

导入与导出

  • 导出为明文 JSON 备份文件，由你自行保存 — 请像对待脚本库一样妥善保管；默认不加密
  • 导入读取你选择的 JSON 文件并在本地合并；不会发送给我们

权限

  • storage — 在本机保存脚本库、偏好与短期注入状态
  • userScripts — 执行你编写的 CSS/JS（在本扩展详情页开启「允许运行用户脚本」；Chrome 138+）
  • tabs — 打开目标网址并在匹配的标签页注入
  • webNavigation — 检测页面加载、跳转、SPA 导航与 iframe 帧以便注入（含可选「自动注入」）
  • windows — 验证目标网址时使用隐藏窗口
  • contextMenus — 工具栏图标右键菜单项，用于打开 Dashboard 与 RunJS 公开产品页；可选网页右键脚本菜单（默认关，设置 → 功能）
  • 可选站点访问 — 保存注入代码时或在「权限」分页申请；拒绝仍可本地保存，注入需已授权；也用于在 Chrome 缓存缺失时从目标页刷新列表图标
  • identity / identity.email — 可选 Google 登录以启用 Drive 同步（展示关联邮箱；仅本机时不使用）
  • alarms — 在开启 Drive 同步时定时触发同步

你编写的脚本

注入的 CSS/JS 由你提供、本地存储，并在 Chrome 用户脚本环境中执行。你需自行对所选网站上的行为负责。
