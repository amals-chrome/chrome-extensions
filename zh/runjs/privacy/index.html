RunJS — 隐私政策

更新日期：2026-08-31

RunJS 以本地优先：脚本与偏好保存在本机 Chrome 存储中。我们不运营脚本库后端，不会把脚本正文或页面内容上传到我们的服务器，也不含分析或广告追踪。

我们存储的数据

以下内容仅保存在你本机的 Chrome 存储中：

  • 脚本库条目（名称、网址、CSS/JS、运行设置、可选缓存图标）
  • 语言、主题与字体偏好
  • Dashboard 编辑中的未保存草稿（session 存储；浏览器会话结束后清除）
  • 打开标签页过程中的短期注入任务（session 存储）
  • 弹窗角标用的短期注入结果（local 存储）
  • 是否已关闭工具栏固定提示（local 存储）

我们不收集的数据

  • 不上传你的脚本、网址或页面内容到 RunJS 服务器
  • 不含分析 SDK、广告追踪，不出售或分享个人数据
  • 不通读浏览历史 — 仅检查与 RunJS 发起运行相关联的标签页 URL（含复用已打开且匹配的标签），以判断何时注入
  • 不下载远程脚本 — 只注入你本地保存的代码

网络使用

  • 打开或测试目标网址时，由浏览器正常访问该站点（不经过我们代理）
  • 列表图标仅在已授权该主机站点访问时从目标站获取：可能读取页面 HTML 以查找 `rel=icon` 链接，再尝试常见根路径 favicon；响应会校验为图片。未授权时使用内置默认图标（不向第三方图标服务请求）

导入与导出

  • 导出为明文 JSON 备份文件，由你自行保存 — 请像对待脚本库一样妥善保管；默认不加密
  • 导入读取你选择的 JSON 文件并在本地合并；不会发送给我们

权限

  • storage — 在本机保存脚本库、偏好与短期注入状态
  • userScripts — 执行你编写的 CSS/JS（在本扩展详情页开启「允许运行用户脚本」；Chrome 138+）
  • tabs — 打开目标网址并在匹配的标签页注入
  • webNavigation — 检测页面加载、跳转、SPA 导航与 iframe 帧以便注入
  • windows — 验证目标网址时使用隐藏窗口
  • contextMenus — 工具栏图标右键菜单项，用于打开 Dashboard 与 RunJS 公开产品页
  • 可选站点访问 — 保存注入代码时或在设置中申请；拒绝仍可本地保存，注入与列表图标获取需已授权；也用于缓存目标页声明的图标（及常见根路径回退）

你编写的脚本

注入的 CSS/JS 由你提供、本地存储，并在 Chrome 用户脚本环境中执行。你需自行对所选网站上的行为负责。
