Two ways to use it

Open and inject — or just open the URL

Save a name, target URL, and optional CSS/JS in the Dashboard. Local-first by default; turn on Google Drive sync when you need it.

Drop-in

Open & inject

Click a saved entry to open the URL and inject after load. Empty CSS/JS means open-only.

Highlights

Real-page ready

Follows redirects, supports SPAs and iframes, with configurable inject timing.

Scoped injection

One URL or all sites; match patterns, auto-inject, and enable/disable per script.

Monaco editor

Completions, hover, and Less/Sass in the Dashboard — theme and fonts follow extension settings.

Proportionate permissions

Site access is requested only when you save inject code; declining still saves locally. Chrome 138+ also needs Allow User Scripts enabled.

Requirements

Chrome 135+

Requires Chrome 135+. To inject saved scripts on Chrome 138+, open chrome://extensions → RunJS details → enable Allow User Scripts. Site access is requested only for origins where you saved inject code.
